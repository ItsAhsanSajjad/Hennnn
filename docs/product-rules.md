# Product Rules

## Confirmed Phase 2 Flows

- Register directly
- Register through `/r/[referralCode]`
- Sign in with username or Pakistani phone
- Access protected dashboard
- Copy referral link
- View profile, activity, notifications
- Admin user search, status control, role control, audit visibility
- Admin plan catalogue management
- Admin payment account management
- User plan browsing and manual purchase order creation
- User payment proof upload to private storage
- Finance payment review
- Approved payment creates a hen asset
- Egg accrual job credits immutable ledger entries
- Admin ledger adjustment with negative-balance protection
- Admin hen suspension

## Disabled in Phase 2

- Payouts
- Guaranteed returns
- Egg selling
- Live referral commissions
- Automated payment settlement
- Public payment-proof URLs
- Referral reward payment
- Real-money payout approval
- Public launch claims

## Confirmed Phase 3 Demo Flows

- User payout-method profile creation with masked identifiers
- Egg-sale eligibility check requiring an approved non-refunded hen asset
- Server-controlled active demo sale rate
- Server-calculated sale amount in integer paisa
- Sale submission with atomic egg reservation
- Sale history and sale detail timelines
- User cancellation while status is `SUBMITTED`
- Finance sale claim, approval, and rejection
- Rejection release through the immutable ledger
- Manual settlement record creation and confirmation
- Paid transition without a second egg debit
- Direct Level 1 referral reward after a qualifying approved purchase
- Referral team and reward history views with masked identity
- Phase 3 reconciliation detection

## Still Disabled After Phase 3

- External payout transfers
- Bank, Easypaisa, JazzCash, wallet, or crypto payout APIs
- Multi-level referral rewards
- Registration-only rewards
- Public financial launch
- Guaranteed sale approval, guaranteed egg value, or guaranteed income
- Real payout-account storage without encryption and provider approval

## Future Rules Requiring Approval

- Buy-before-sell eligibility
- Purchase lifecycle
- Hen activation lifecycle
- Egg generation schedule
- Egg sale pricing
- Payout review and settlement
- Referral reward eligibility
- Refunds, reversals, and dispute handling
- Compliance disclosures

No user-facing copy may claim guaranteed profit, government approval, FBR verification, or risk-free earnings unless independently verified documentation is supplied.
